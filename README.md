# Ори · «Поймай звезду» — МТС Деньги

Интерактивный прототип: 3D‑такса Ори ловит звезду дня и играет в мяч. Один экран, three.js, без бэкенда.

- Онлайн: https://andreyaak.github.io/ori-catch-a-star/
- Управление: «Поймать звезду» — сцена с падающей звездой и фразой дня (одна в день, сброс в меню ⋯); погладить по голове; команды «Дай лапу», «Кувырок», «Показать животик»; «Бросить мяч» + тап по экрану; лежащий мяч можно швырнуть жестом, он отскакивает от краёв экрана, Ори догоняет и приносит.
- Вращение: перетаскивание; зум: колесо / щипок; двойной клик — сброс.

Файлы: `index.html`, `assets/bundle.js` (three.js + логика), `assets/ori.glb` (модель + все анимации), шрифты МТС, логотипы.
